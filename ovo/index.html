OVO-Bench

Online video understanding in three modes: backward tracing, real-time visual perception, and forward active responding (the model must wait, count or follow steps as the stream continues). Twelve tasks.

Statistics

  • 644 videos from twelve source datasets; Ego4D is the largest public one (523 records).
  • 1,640 annotation records with 3,035 questions. In the three forward tasks the same question is asked again several times as the video goes on, so one record holds several questions.
  • A question is asked at a point in time, 1:56 into the video on median. The model sees only the video up to that point.

Answer format: what the model has to produce

  • Multiple choice1,468 questionsbackward tracing and real-time perception; 1,371 with 4 options, 42 with 2 options, 42 with 3 options, 13 with 5 options
  • A number698 questionsrepetition event count: the count so far at each query
  • Yes or No869 questionsstep recognition (629 queries: is this step being performed now) and clue reveal (240: can the question be answered yet)

Evaluation

Multiple-choice tasks
Backward tracing and real-time perception: a query is correct if the ground-truth answer appears in the reply.
Repetition event count (REC)
At each query, correct if the number in the reply equals the count so far.
Step recognition (SSR) and clue reveal (CRR)
At each query the model answers Yes or No; correct if it matches the expected answer.
Aggregation
A task is the mean over its queries (\(F_q = 1\) if query \(q\) is correct), a mode is the mean of its tasks, and Overall is the mean of the three modes.
\[\mathrm{Acc}_{\text{task}}=\frac{1}{Q}\sum_{q=1}^{Q}F_q,\qquad \mathrm{Overall}=\frac{\text{Backward}+\text{Real-time}+\text{Forward}}{3}\]
